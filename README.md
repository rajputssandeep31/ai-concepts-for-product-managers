# AI Concepts Every Product Manager Should Know

**A sequential guide from AI foundations to product decisions about data, tools, agents, quality and economics.**

A growing learning guide maintained by Sandeep Singh Rajput. This AI-assisted first edition was approved for public release on 6 October 2026. Examples are fictional and use no employer or customer information.

## Start here

You do not need to write code to read this guide. Start with [Lesson 01: AI, machine learning and generative AI](01-ai-ml-generative-ai.md). Each lesson builds the vocabulary needed for the next one.

The goal is to help you ask better questions in discovery, architecture discussions, prioritization and launch reviews. Definitions are useful when they change a decision: which capability to build, what data it needs, how it can fail, and what evidence would justify release.

All ten lessons contain a plain-language explanation, a worked example, a PM decision, a common misconception and a short exercise with an answer. Technical definitions link to primary sources; product examples and recommendations are the guide's own illustrations.

## How this guide evolves

Stable concepts come before vendor features. Add lessons in prerequisite order, record meaningful changes in [the changelog](CHANGELOG.md), and date-check sources when revising. Version-specific behavior should name the relevant version. Model prices, rankings and limits should be verified when needed rather than embedded as timeless facts.
